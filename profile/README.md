# aeogeo.site

**Get found by AI, not just search.**

aeogeo checks whether ChatGPT, Perplexity, Google AI Overviews and other answer engines can read, trust and cite your site. You get deterministic AEO/GEO checks and an evidence-graded rulebook your coding agent can apply directly.

- **Always-current research.** An AEO/GEO rulebook that keeps up as AI engines change, so your agent works from what's true now.
- **Deterministic checks** for everything code can actually verify.
- **Works where you work:** an MCP server for your agent, a CLI, and CI.
- **Free URL scan** to see where you stand.
